Como usar ​

Para estudar Leia na ordem, do simples ao avançado. Cada tema leva 10–15 minutos e tem código.

Antes da entrevista Use Na entrevista em cada tema para revisar rápido.

Para praticar Faça os exercícios no fim de cada tema. Leve os patterns para os seus projetos.

Com mentor O handbook entra no programa de mentoria, para uma preparação organizada rumo à vaga.
